# Vehicle-Management-System-to-Reduce-Risky-Factors-Using-Embedded-Technology-Enhanced-With-Wi-Fi

This project is an embedded vehicle safety system designed to monitor driver condition, detect accidents, and send emergency information through Wi-Fi. The system combines accident detection, drowsiness monitoring, heartbeat sensing, GPS tracking, and server-based updates.

The main goal of this project is to reduce risky driving conditions and improve emergency response by continuously monitoring vehicle and driver status.

## Key Features

- Driver drowsiness detection using camera and OpenCV
- Heartbeat monitoring using heartbeat sensor
- Accident detection using vibration sensor
- GPS-based vehicle location tracking
- Wi-Fi-based server data update
- Buzzer alert during abnormal or accident conditions
- Motor speed reduction during risky driver condition
- Emergency alert support for accident response

## Hardware Used

- Raspberry Pi
- PIC Microcontroller
- Camera Module
- Heartbeat Sensor
- Vibration Sensor
- GPS Module
- Wi-Fi Module
- Buzzer
- DC Motor
- Motor Driver
- SMPS Power Supply

## How It Works

1. The camera monitors the driver’s eyes for drowsiness detection.
2. OpenCV is used to detect eye status and identify drowsy driving.
3. The heartbeat sensor monitors the driver’s health condition.
4. The vibration sensor detects accident impact or abnormal vehicle vibration.
5. GPS captures the accident location.
6. Wi-Fi updates the vehicle status and location to the server.
7. The buzzer alerts nearby people during accident or abnormal conditions.
8. The motor speed can be reduced when risky conditions are detected.
